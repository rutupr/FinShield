# Project Contract

## Purpose

Build and maintain FinShield as an explainable loan and insurance decision-support platform.

## Commitments

- Preserve the existing React/Vite architecture and working functionality.
- Keep AI, UI, and data-handling concerns separated.
- Deliver transparent recommendations with supporting factors.
- Ensure a human reviewer makes each final decision.
- Protect credentials and sensitive financial information.

## Out of scope

The system must not autonomously approve, reject, or issue financial products without human review.
