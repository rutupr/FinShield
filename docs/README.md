# FinShield

FinShield is an intelligent, explainable decision-support platform for loan underwriting and insurance analysis. It analyzes applicant information and financial documents to help reviewers evaluate creditworthiness, fraud indicators, insurance adequacy, and the potential impact of unexpected events.

The product uses React, Vite, JavaScript/JSX, and CSS. Its planned AI integration uses NVIDIA AI for structured document analysis and explainable insights. Human reviewers retain final approval authority.

## Quick start

```bash
npm install
npm run dev
```
